# Sneha Murali Portfolio

A buildless portfolio for Web3 content, journalism, communications, social media, community and ecosystem business development.

## Files

- `index.html`: page content, work cards, articles, experience and contact links.
- `portfolio.css`: responsive custom styling.
- `work.js`: detailed case studies and proof-image captions.
- `portfolio.js`: filtering, search, accessible project dialogs, image enlargement, mobile navigation and copying the email address.
- `assets/images`: optimized images extracted from Sneha's supplied portfolio documents.
- `assets/fonts.css`: locally hosted fonts.
- `assets/copyneat.css`: retained styling from the selected Copyneat reference.
- `vercel.json`: static hosting configuration with no install or build step.

## Run locally

From this directory:

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`. No Node dependencies or backend services are required. Contact links use email, telephone and the supplied social profiles. Video links open the supplied Google Drive portfolio and Instagram reels.

## Deploy

Import this GitHub repository into Vercel. If these files are stored in a repository subdirectory, select that directory as the project root. Use the Other framework preset and the static configuration in `vercel.json`.

## Content notes

The site was prepared from the supplied portfolio documents, with Qatobit presented as a previous role and n1stake added from the current work context. Some supplied documents contain conflicting month ranges; those roles are shown at year level. Audience numbers and search rankings describe historical evidence. The Discord moderation image is labeled illustrative. No testimonials, follower-acquisition claims, or completed delegation awards were invented.
